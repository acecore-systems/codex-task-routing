# 0.23.1 検証記録

2026-10-29、Windows・Python 3.13 の専用 worktree で、起動フックの方針出力が 8,000 文字を超えて失敗する問題を確認しました。対象の現設定を値を表示せず評価した場合、修正前は 8,210 文字、修正後のコードでは 7,449 文字となり、方針を配信できました。実設定と観測台帳の変更は行っていません。

一時 Codex ホームで、長いカスタム方針、200 文字のインストール先、最大長の campaign と task ID、欠測記録、次回予約、通常 Chat 設定を組み合わせ、方針全文と観測状態が上限内に入ることを検証します。極端に長いカスタム方針では従来どおり無言で途中を切らず、明示エラーになります。フックの実信頼や実際の通常作業での測定は別途確認が必要です。
