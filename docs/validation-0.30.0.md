# 0.30.0 の検証範囲

方針の意味変更として、推奨する親の開始設定と役割別の既定を更新しました。実際の親設定、有効なoverride、既存担当、認証・Chat所有者・承認の境界は変更しません。推薦helperには任意のconsultation booleanを追加し、省略時の既存動作を維持します。フックは方針を案内します。モデルの起動や操作の認可は行いません。

Windows / Python 3.13で全438件のテストとパッケージ検査が通過しました。一時Codexホームでの既定方針の生成、個人overrideの反映、推薦helperへの旧入力を含みます。今回の変更は実際のCloud・通常Chat・各モデルの実行や品質を検証するものではありません。配布・インストールも行っていません。
