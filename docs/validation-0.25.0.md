# 0.25.0 の検証記録

## 変更と範囲

既定方針は、ローカル現物が必要な場合にCloud・通常Chatと標準子の適合性を別に評価し、並列条件を作るためだけに親へ通常実装を残さない意味へ変更しました。適任の継続担当、短い仕事、密結合、親の正当な実装、ホスト制約、直列委譲の具体的な追加価値とホスト許可は維持します。モデル、effort、承認境界は変更していません。

配布面では既定summary・詳細・SKILL・起動文を更新しました。カスタムsummaryは既定summaryを置換したままで、上書き・自動移行しません。カスタム分岐の起動文は実アクセスと有効方針の確認を促し、具体的な既定文をカスタム原則に強制しません。詳細にも個別overrideがある場合を含め、実際の有効方針と矛盾を確認する必要があります。方針hashとrevisionが変わるため既存観測のsampling keyと区別します。

## 自動検証と限界

Windows・Python 3.13の権限付きテストプロセスで `python -m unittest discover -s tests -v` は393件成功しました。`python scripts/check_package.py` は成功しました。起動文・描画文・カスタムoverride保持・短い仕事やホスト制約の文面、既存イベント処理を合成入力で検証しています。最初に変更前の全件をサンドボックス内で実行した際は一時ディレクトリやハードリンクの権限制約で失敗し、権限付きプロセスで392件成功しました。

新バージョンは稼働環境に導入しておらず、実ホストへの新しい起動文の配送、モデルによる運用、追加後の標準子起動、Cloud・通常Chat、他OSでの動作は未検証です。文字列・合成イベントの検査は委譲の実行や改善効果を保証せず、親子の使用量・工数の比較も行っていません。[別セッションの限定調査](routing-diagnosis-2026-11-03.md)と混同しないでください。

稼働中のCodex設定、利用者のAGENTS、認証情報、会話履歴は変更していません。
