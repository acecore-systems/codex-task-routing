# 0.30.1 の検証範囲

配布変更として、観測した子の終了後、次の親の作業前に一度だけ条件付きの案内を返します。終了は未完了の証拠ではなく、ツール数・本文・引数から担当範囲を判断しません。動作中の子や観測した担当連絡は案内を抑制し、親の受入・権限判断・独立作業やホストの制約を維持します。入力時の固定案内にも同じ担当の継続を加えたため、カスタム summary を置換せずに案内します。停止状態はハッシュ化されたセッション識別子と時刻のみで保持し、既存の期限・件数整理を適用します。イベントが届かない場合や連絡先を区別できない場合は案内の網羅性を保証できません。

Windows / Python 3.13 で全441件が通常権限で通過し、パッケージ検査も通過しました。追加したターン切替のテストを含む parent guard 15件も通過しました。最初のサンドボックス実行では一時ファイルのハードリンク作成が拒否され、1失敗・8エラーでした。テストは一時ホームでの合成イベントであり、0.30.1 の実ホストでのイベント配送・助言反映は未検証です。利用環境へのインストールは行っていません。
