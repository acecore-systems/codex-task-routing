# 0.29.0 検証記録

通常推薦でrootの同一目的の作業も、明示opt-in・text-only適合・local-auth adapter・対象/資料の承認・host/委譲条件を確認した場合にHaiku候補として扱います。適任の既存委譲先とCloud/Pro優先、親専用や密結合時の扱いを維持します。提案・編集・テスト・受入は別で、推薦は実行許可を発行しません。

隔離Codexホームで明示設定の有効・無効・破損、rootのみの起動文、実hookプロセス、既存方針と条件分岐を検証します。利用者の稼働中設定・認証・秘密値は変更せず、今回の追加方針でAPIを呼びません。

別途、親担当は従来の固定対象経路でローカル認証を通じたHaikuの応答、合成リポジトリの1ファイル編集と2件のテストを確認しています。この限定実績は本変更後の通常推薦・toolなし提案adapter・任意の作業への適用を実証しません。対象hostでのadapter導入、承認付き初回提案、実作業への適用・テスト、コストと品質の比較は別途検証が必要です。Windowsでの一般的な無人編集隔離は確認していません。

Windows / Python 3.13で全435件のテストと `python scripts/check_package.py` が成功しました。固定inbox提案adapterとの実送受信はこの版の検証に含みません。
