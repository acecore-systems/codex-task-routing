# Backlog

## 通常Chat一時Chatのブラウザー不要化

成功条件は未達です。通常Chatの一時Chatを新規作成し、`6 Pro` を指定して本文送信と最終回答取得まで行う、正規に公開された外部入口が必要です。現時点では、非公開HTTP、認証情報、会話データ、OSディープリンク、MCPのserver pushを代替手段にしません。

## 独自MCPの常用接続

一時チャットからMCPで依頼を取得し結果を返す架空データの疎通は確認済み。常用化には認証付きの安定した接続先、依頼ごとのアクセス制限と有効期限、重複・競合結果の扱い、接続停止時の運用を整える。モデルAPIは呼び出さず、通常Chatの利用枠を使う条件を維持する。検証用の認証なし一時トンネルを実データの常用先にはしない。
