# 0.28.0 の検証記録

## 方針と計画契約

親が既に把握・着手したことだけで親に保持せず、対象・素材・決定・制約・受入・権限を短く渡し、将来の編集・試行・検証の文脈分離を引継ぎ便益に含めます。適任の既存委譲先、短い作業、具体的な親専用操作、親子間の実際の密結合、役割・深さ・ホストと承認の境界を維持します。新トップレベルセッションの作成とは分けて判断し、同モデルへの無用な移管を増やしません。

`session_plan.py recommend` は任意の `owner.kind`、`work.parent_only`、`work.context_separation_benefit` を受け付けます。親を明示し、同じ目的の単位が移管可能で総便益があり、親子間に密結合がなく、標準子のホスト条件が満たされる場合は標準子を推薦します。親専用やホスト拒否は維持し、便益・アクセスが不明なら不足として扱います。文脈分離がfalseでも別の具体的便益があれば候補にできます。適任の委譲済み担当は継続し、独立repoでのCloud優先は維持します。既存入力でkindを省略した場合は旧動作を保ちます。推薦は実行許可ではありません。

## 検証と限界

Windows / Python 3.13の権限付きテストプロセスで `python -m unittest discover -s tests -v` は422件成功し、`python scripts/check_package.py` は成功しました。親・既存委譲先の区別、親専用、ホストの拒否とunknown、別の引継ぎ便益、旧入力、Cloud優先を合成入力で検証しています。これは実ホストでの案内配送や委譲実行、使用量削減を証明しません。

カスタムsummaryは既定summaryを置換し、新しい既定文を自動では受け取りません。0.28.0の実ホスト配送・実委譲、Cloud・通常Chat・Haikuや他OSへの影響は未検証です。稼働中の旧版参照を破壊するライブupgradeは避け、導入後の版・フック信頼・実配送を別々に確認します。
