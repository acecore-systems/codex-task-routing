# 0.30.1 の検証範囲

配布変更として、観測した子の終了後、次の親の作業前に一度だけ条件付きの案内を返します。終了は未完了の証拠ではなく、ツール数・本文・引数から担当範囲を判断しません。動作中の子や観測した担当連絡は案内を抑制し、親の受入・権限判断・独立作業やホストの制約を維持します。入力時の固定案内にも同じ担当の継続を加えたため、カスタム summary を置換せずに案内します。停止状態はハッシュ化されたセッション識別子と時刻のみで保持し、既存の期限・件数整理を適用します。イベントが届かない場合や連絡先を区別できない場合は案内の網羅性を保証できません。

入力時には、入口の語ではなく受入条件と完了工程から全体の所有者を選び、検証・切り分け・通常修正・再試験を一つの実行単位とするよう案内します。有効なカスタム方針を尊重し、役割を固定しません。既定役割の具体例はREADMEに記載します。

Codexのshell実行については、公式の[hook tool coverage](https://learn.chatgpt.com/docs/hooks#tool-coverage)に記載された `Bash` をmatcherと作業名に含めます。子の終了後に `Bash` の合成PreToolUse入力で案内が返ることを検証し、従来の名前も維持します。

Windows / Python 3.13 で全442件が通常権限で通過し、パッケージ検査も通過しました。最初のサンドボックス実行では一時ファイルのハードリンク作成が拒否され、1失敗・8エラーでした。テストは一時ホームでの合成イベントであり、0.30.1 の実ホストでのイベント配送・助言反映は未検証です。利用環境へのインストールは行っていません。
